# IR-0001 波次计划（spec PR #2 已合并，verdict=survived；本文件为开卡依据）

> 波次边界按"何时能接触现实"切（组织 PLAYBOOK §3 先例），不按工作量切。
> 每波次结束产出一个人类 5 分钟内可验收的东西。
> 平台接入顺序按 spec DECISION-4：抖音先行、小红书次之、视频号殿后；
> Top 热门评论情感分析、Word 导出后置（AC-14 以 PDF 满足）。
> 每卡纪律（BUDGET-1）：一个 PR 一件事、diff < 400 行、测试先于实现（fail-before）。
